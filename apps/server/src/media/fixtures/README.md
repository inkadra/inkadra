# Media worker fixtures

Small files the worker tests read. Each is a few kilobytes; keep new ones that small.

| File                | What it is                                                                                                                           | Made with                                                                                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gradient.heic`     | A HEIC photo, as iPhones write them                                                                                                  |                                                                                                                                                                                                  |
| `prores-proxy.mov`  | 0.5 s of ProRes 422 Proxy, 64×36 at 12 fps, with PCM sound                                                                           | `ffmpeg -f lavfi -i color=c=0x3366cc:s=64x36:r=12:d=0.5 -f lavfi -i sine=f=440:d=0.5:sample_rate=8000 -c:v prores_ks -profile:v 0 -c:a pcm_s16le -ac 1 -shortest prores-proxy.mov`               |
| `h264-opus.mkv`     | 0.5 s of H.264 with Opus sound in Matroska                                                                                           | `ffmpeg -f lavfi -i color=c=0x33cc66:s=64x36:r=12:d=0.5 -f lavfi -i sine=f=440:d=0.5:sample_rate=8000 -c:v libx264 -pix_fmt yuv420p -c:a libopus -b:a 8k -ac 1 -shortest h264-opus.mkv`          |
| `orientation-6.dng` | A minimal DNG: a 320×200 JPEG preview (red left, blue right) in IFD0, an 8×8 CFA image, EXIF orientation 6, Make, Model and exposure | `node make-dng.mjs preview.jpg orientation-6.dng`, the preview from `ffmpeg -f lavfi -i color=c=red:s=160x200 -f lavfi -i color=c=blue:s=160x200 -filter_complex hstack -frames:v 1 preview.jpg` |
| `two-pages.pdf`     | Two pages: A4 portrait, red over blue, then A4 landscape, green                                                                      | Written by hand, its cross-references rebuilt by `qpdf raw.pdf two-pages.pdf`                                                                                                                    |
| `encrypted.pdf`     | The same, encrypted with a password to open (`secret`)                                                                               | `qpdf --encrypt --user-password=secret --owner-password=owner --bits=256 -- two-pages.pdf encrypted.pdf`                                                                                         |
